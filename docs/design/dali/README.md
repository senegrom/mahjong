# Dalí mahjong tile set

A new surrealist tile face set for the mahjong game. The first six approved faces are deliberately spread across the suits and honours so the visual language can be evaluated in real play before the remaining faces are designed.

## Approved first studies

| File | Tile | Direction |
| --- | --- | --- |
| `Pin1.svg` | 1 dot | Soft Time — an impossibly soft pocket watch melting over a desert shelf |
| `Pin5.svg` | 5 dots | Levitation — five polished, slightly softened disks floating over the desert |
| `Sou1.svg` | 1 bamboo | Stilt Bird — one elongated surreal crane-like bird with impossibly long legs |
| `Sou2.svg` | 2 bamboo | Elastic Growth — two sinuous segmented bamboo stalks; all visible colour remains green |
| `Man8.svg` | 8 characters | Impossible Stone — ivory 八 above a sculptural vermilion 萬 |
| `Chun.svg` | Red dragon | Molten Ruby — translucent ruby-red 中 stretched into an uncanny molten form |

The other 28 faces use `web/public/tiles/dali/placeholders/placeholder.svg` until they receive approved artwork.

## Presentation

The set follows the existing tile system's 300 × 400 face and full-face artwork approach. The six first studies are compact SVG artwork derived from the approved concept directions, with no physical tile mock-up or outer frame. Numbered tiles remain countable at game size.

Choose **Options → Tile face → Dalí**. The preference is persisted with the existing settings mechanism. All 34 Dali tile identities are included in the preload inventory: six approved faces plus one shared placeholder for the remaining identities.
