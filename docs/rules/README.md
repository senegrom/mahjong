- `EMA-Riichi-rules-2025-EN.pdf` — EMA Riichi Competition Rules, 2025 edition
  (version 1.1, August 2025), in force since 1 January 2026. **Authoritative.**
  Source: http://mahjong-europe.org/portal/images/docs/Riichi-rules-2025-EN.pdf
- `EMA-Riichi-rules-2016-EN.pdf` — the previous edition, kept for the change
  history only. Source: http://mahjong-europe.org/portal/images/docs/Riichi-rules-2016-EN.pdf
